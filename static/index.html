📖 Справка

Инструкции по настройке приложения

Получение client_secret.json
🔑
Файл авторизации Google OAuth 2.0
Этот файл разрешает приложению загружать видео на ваш YouTube-канал от вашего имени. Он создаётся один раз в Google Cloud Console и привязан к конкретному проекту.
1
Откройте Google Cloud Console
Перейдите на console.cloud.google.com. Войдите в аккаунт Google, который владеет YouTube-каналом.
Нажмите Select a project → New Project → введите название → Create.
2
Включите YouTube Data API v3
В левом меню: APIs & Services → Library.
В поиске введите YouTube Data API v3 → нажмите на неё → Enable.
3
Настройте экран согласия OAuth
APIs & Services → OAuth consent screen.
Выберите External → Create.
Заполните обязательные поля: App name (любое), User support email, Developer contact email.
Нажмите Save and Continue через все шаги до конца.
4
Создайте учётные данные OAuth 2.0
APIs & Services → Credentials → + Create Credentials → OAuth client ID.
В поле Application type выберите Desktop app.
Название — любое. Нажмите Create.
5
Скачайте JSON-файл
В появившемся окне нажмите Download JSON.
Файл называется примерно client_secret_123...apps.googleusercontent.com.json.
Это и есть ваш client_secret.json.
✓
Добавьте канал в приложение
Перейдите в раздел → нажмите ➕ Добавить канал → перетащите скачанный файл в форму.
⚠️
Квоты YouTube API
Один Google Cloud проект = ~6 загрузок в день.
Нужно больше — создайте второй проект Google Cloud и добавьте второй client_secret.json.
💡
Предупреждение Google при авторизации
При авторизации может появиться экран «Google hasn't verified this app».
Нажмите Advanced → Go to app (unsafe) — это нормально для личного использования.
🔴
Обязательно: перевести приложение из Testing в Production
Пока Google Cloud проект находится в режиме Testing, refresh-токены OAuth периодически аннулируются Google. Это приводит к ошибке invalid_grant: Token has been expired or revoked и видео перестают загружаться без предупреждений.

Нужно сделать один раз для каждого Google Cloud проекта.
1
Откройте Google Cloud Console и выберите проект
Перейдите на console.cloud.google.com.
В верхней строке нажмите на название текущего проекта → выберите нужный проект из списка.
Повторите все шаги для каждого проекта отдельно.
2
Перейдите в настройки OAuth
В левом боковом меню выберите APIs & Services → OAuth consent screen.
Если интерфейс обновлён (Google Auth Platform): в левом меню нажмите Audience.
3
Проверьте текущий статус
На странице найдите блок Publishing status или User type.
Если написано Testing — нужно публиковать.
Если написано In production — уже готово, переходите к следующему проекту.
4
Опубликуйте приложение
Нажмите кнопку Publish App (или Push to production).
Появится диалог с предупреждением — нажмите Confirm.
Статус изменится на In production.
✓
Повторите для всех проектов и переавторизуйте каналы
Повторите шаги 1–4 для каждого Google Cloud проекта, который используется в приложении.
После публикации — переавторизуйте каналы, которые показывают ошибку: зайдите в → нажмите Авторизовать рядом с каналом.
Токены, выданные после публикации, не истекают пока приложение активно используется.
